## Executive Summary

This document outlines the monthly infrastructure costs required to operate the thehodl.fun backend platform at growth stage, supporting 1,000 to 5,000 concurrent users. The architecture is designed for high availability, real-time performance, and cost efficiency using modern cloud-native services.

**Total Estimated Monthly Cost: $1,000 USD**

---

## Platform Overview

thehodl.fun is a universal token launchpad platform built on Push Chain, enabling users to launch and trade ERC20 tokens with bonding curve mechanics. The backend infrastructure supports:

- **REST API** for token operations and user management
- **Real-time WebSocket** connections for live price updates and trade notifications
- **Blockchain Indexer** for synchronizing on-chain events
- **Background Workers** for metrics calculation, alerts, and data processing

## Detailed Cost Breakdown

### 1. Compute Services (Cloud Run)

Cloud Run provides serverless container hosting with automatic scaling and pay-per-use billing.

| Service | vCPU | Memory | Min Instances | Max Instances | Monthly Cost |
|---------|------|--------|---------------|---------------|--------------|
| API Server | 2 | 2 GiB | 1 | 6 | $250 |
| WebSocket Server | 1 | 2 GiB | 2 | 6 | $150 |
| Blockchain Indexer | 1 | 1 GiB | 1 | 2 | $90 |
| Background Worker | 1 | 1 GiB | 1 | 4 | $80 |

**Compute Subtotal: $570/month**

#### Pricing Basis:
- CPU: $0.000024 per vCPU-second
- Memory: $0.0000025 per GiB-second
- Source: https://cloud.google.com/run/pricing

#### Service Justifications:

**API Server**
- Handles REST API requests for token creation, trading, and user operations
- Rate-limited to 10 req/sec per client with 3-tier throttling
- Auto-scales based on request volume and CPU utilization

**WebSocket Server**
- Maintains persistent connections for real-time price and trade updates
- Redis adapter enables horizontal scaling across multiple instances
- Minimum 2 instances ensure high availability for connected clients

**Blockchain Indexer**
- Polls Push Chain every 5 seconds for contract events
- Processes CreateCurve, Buy, Sell, and graduation events
- Single instance with circuit breaker pattern for RPC resilience

**Background Worker**
- Calculates OHLC candlestick data across 6 time intervals
- Updates leaderboards every 30 seconds
- Processes portfolio updates and alert notifications
- Scales to zero during low activity periods

## Scaling Considerations

### Vertical Scaling (within current architecture)
- Cloud SQL can scale to 8 vCPU, 32 GB without migration
- Redis can expand to 10 GB within same tier
- Cloud Run instances can scale to 8 vCPU, 32 GB per container

### Horizontal Scaling (future growth beyond 5K users)
- Add read replicas to Cloud SQL for query distribution
- Implement Redis Cluster for sharded caching
- Deploy to multiple regions for global low-latency access

# Smart Contract Security Audit Cost Estimate

## Overview

A professional security audit is essential before mainnet deployment to ensure the safety of user funds. The thehodl.fun smart contract suite implements complex DeFi mechanics including bonding curves, AMM trading, UUPS upgradeable proxies, and Uniswap V3 integration for token graduation.

---

## Codebase Summary

| Metric | Value |
|--------|-------|
| Total Lines of Code | ~3,500 SLOC |
| Number of Contracts | 6 core contracts + libraries |
| Complexity Level | High (DeFi/AMM) |

### Core Contracts

| Contract | Description | Complexity |
|----------|-------------|------------|
| Core.sol | Entry point for all user interactions (buy, sell, create) | High |
| BondingCurveFactory.sol | Deploys token + bonding curve pairs, manages configuration | High |
| BondingCurve.sol | AMM logic with constant product formula (k = x * y) | High |
| Token.sol | ERC20 upgradeable with controlled minting | Medium |
| FeeVault.sol | ERC4626 vault for platform and creator fees | Medium |
| WPUSH.sol | Wrapped native token for ERC20 compatibility | Low |

### Security-Critical Areas

- **AMM Mathematics**: Bonding curve price calculations and virtual reserve mechanics
- **Reentrancy Protection**: Multiple external calls during trading operations
- **Access Control**: Role-based permissions with UUPS upgrade authorization
- **Integer Precision**: Handling large token supplies (1 billion) with 18 decimals
- **DEX Integration**: Uniswap V3 pool creation during graduation
