## Meme Creation Guidelines (2026 Edition)

### Do's
- Keep text SHORT (CT attention span = 2 seconds)
- Use current CT slang naturally
- Be self-deprecating
- Reference shared experiences
- React to current events/trends fast
- Test formats before committing

### Don'ts
- Don't use formats from 2017
- Don't explain the joke
- Don't force hodl.fun into every meme
- Don't punch down
- Don't be corporate
- Don't use dead formats ironically (it's still dead)

### Current Slang Reference (2026)
- ser / fren / anon
- based / cringe
- it's giving...
- no cap / fr fr
- down bad
- touch grass
- we're so back / it's so over
- main character energy
- the math isn't mathing
- understood the assignment

### Quality Check Before Posting
1. Would you actually laugh at this?
2. Does it work without explanation?
3. Is the hodl.fun angle natural or forced?
4. Is the format current or dated?
5. Would CT screenshot this positively?

## Format Lifespan Awareness

Meme formats have lifecycles:
1. **Emerging** - Early adopters, high engagement
2. **Peak** - Everyone uses it, still effective
3. **Declining** - Overused, engagement drops
4. **Dead** - Using it signals you're out of touch

**Monitor CT weekly for:**
- New formats emerging
- Formats becoming overused
- Formats dying

**Adjust strategy accordingly.**
